# openEHR - HL7 FHIR Collaboration: International Patient Summary Working Group

This repository contains openEHR data models that are being developed to meet the following objectives:

**Objective 1:** ​Publish into CKM International, a draft set of openEHR archetypes and templates based on FHIR IPSv2.0 IG for IPS Required datasets (Problem List, Allergies and Intolerances, Medication Summary)

**Objective 6:** Publish a draft set of openEHR archetypes and templates based on FHIR IPSv2.0 IG for IPS Recommended datasets to openEHR CKM

- **Prerequisite:** openEHR International Patient Summary Template (based on FHIR IPS IG v1.0.0): https://ckm.openehr.org/ckm/templates/1013.26.376

- **FHIR IPS IG v2.0.0:** https://build.fhir.org/ig/HL7/fhir-ips/en/ 

- **New openEHR IPS templates will be shared in this CKM repository:** https://ckm.openehr.org/ckm/incubators/1013.30.135

- **More information about the working group:** https://confluence.hl7.org/spaces/PC/pages/391645300/HL7+openEHR+Collaboration+-+International+Patient+Summary+Alignment+Workstream
